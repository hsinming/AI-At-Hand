# AI at Hand 🤖

**AI at Hand** 是一套 Windows 桌面小工具，讓你在任何應用程式中選取文字或截圖，按一下快捷鍵，就能立即取得 AI 的回覆（支援 Markdown 排版）。

## ✨ 主要功能

* **自訂提示詞選單** — 內建 57 組醫療專用提示詞（放射科報告、腫瘤分期、RADS 分級等），可透過系統匣的 **Prompt Management**、**Menu Editor** 視窗新增或修改，也可以直接編輯 `prompts.yaml`、`menu.yaml`。
* **四家 AI 服務** — OpenRouter、OpenAI、Anthropic、Gemini，各自有固定的連線設定與模型清單（`models.json`）。可在 Settings 設定預設服務商與模型，也能針對個別提示詞覆寫。
* **彈出視窗顯示回覆** — 支援程式碼高亮、表格排版、一鍵複製。
* **多輪對話** — 可針對回覆繼續追問，保留對話脈絡。
* **截圖辨識** — 全螢幕或框選截圖，傳給支援圖片的 AI 模型分析。
* **可調整思考深度** — 支援延伸推理的模型，可依提示詞個別設定推理強度（依服務商而定，最低 `minimal` 到最高 `max`）。
* **自動貼上** — 也可以設定成直接把回覆貼回原本的視窗，不用另外開視窗。
* **病歷去識別化** — 內建台灣病患資料（姓名、身分證字號、病歷號、日期等）自動遮蔽，預設開啟，可依需求個別關閉。
* **Email 驗證碼登入** — 輸入授權 Email 收取一次性 6 位數驗證碼；驗證後 7 天內免再輸入，並與該台電腦綁定。
* **首次啟動精靈** — 第一次執行時會要求先輸入至少一家 AI 服務商的 API 金鑰才能繼續使用。
* **手動更新** — 系統匣選單可檢查並下載新版本，每一步都需使用者確認；僅編譯後的 `.exe` 版本可用。

## 🚀 開始使用

### 事前準備

* **Microsoft Edge WebView2 執行環境** — Windows 10/11 通常已內建，若缺少會自動提示安裝。
* **授權 Email** — 你的 Email 需在授權名單中；首次啟動（之後約每週一次）需用寄到信箱的一次性驗證碼驗證。

### 安裝步驟

1. 下載最新版的 **`AI@Hand.exe`**。
2. 執行 `AI@Hand.exe`，第一次啟動會自動產生設定檔。
3. **驗證 Email** — 跳出的視窗會要求輸入授權 Email，接著輸入寄到信箱的 6 位數驗證碼。
4. **首次啟動精靈** 會要求輸入至少一家 AI 服務商的 API 金鑰（建議使用 [OpenRouter](https://openrouter.ai/)，一組金鑰就能用 Claude、GPT、Gemini 等多種模型）。
5. 需要的話，可從**系統匣圖示 → Settings** 調整快捷鍵、預設服務商/模型等設定。
6. 可從**系統匣圖示 → Prompt Management** 新增或編輯提示詞，從 **Menu Editor** 調整選單排列。

## ⌨️ 快捷鍵

| 按鍵 | 功能 |
|------|------|
| `` ` ``（反引號） | 打開提示詞選單（不會自動選取文字） |
| **Ctrl+Alt+K** | 自動選取文字 → 打開提示詞選單 |
| **Ctrl+Alt+J** | 自動選取文字 → 直接執行預設提示詞 |
| **Ctrl+F11** | 截取全螢幕畫面 |
| **Ctrl+F12** | 框選截取畫面 |
| **CapsLock + `** | 暫停 / 恢復所有快捷鍵 |

> 💡 快捷鍵可以在系統匣 **Settings** 視窗裡自行更改。

## 🖥️ 使用方式

1. 在任何程式中選取一段文字（或用快捷鍵截圖）。
2. 按下快捷鍵，從選單中選一個提示詞。
3. AI 回覆會顯示在彈出視窗中；也可以按 **Chat** 按鈕繼續追問。
4. 若該提示詞設定為「自動貼上」，回覆會直接取代原本選取的文字。

## 📝 自訂提示詞

* 系統匣 **Prompt Management** 視窗可以新增、編輯、刪除自己的提示詞，不需要手動改檔案。
* 內建提示詞也可以在這裡調整（服務商、模型、思考深度、貼上方式等），但無法直接看到內建的系統提示詞內容，需另外點選「自訂提示詞內容」才能修改。

## 🔒 病歷去識別化

傳送文字給 AI 之前，系統會自動遮蔽偵測到的病患姓名、身分證字號、病歷號、生日等敏感資訊。此功能預設開啟，如某個提示詞不需要，可在 Prompt Management 中關閉。

## 🔄 檢查更新

系統匣選單的 **Check for Updates** 可以檢查是否有新版本：

1. 若有新版本，會顯示版本號、發布日期與更新內容摘要。
2. 確認後會自動下載、安裝並重新啟動。

> ⚠️ 此功能僅在**編譯後的 `.exe`** 版本可用；若是直接執行原始 `.ahk` 檔案，此選項會顯示為灰色無法點選。
